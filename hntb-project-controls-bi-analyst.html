02  —  Challenges & My Response

What HNTB Needs  ·  What I Bring

Four challenges drive this role. Each maps to production work I delivered in an enterprise environment — using the same tools, the same KPIs, and the same governance requirements HNTB operates under.

The Challenge
01
Power BI Dashboards for Project Cost and Schedule Control

Project managers on large infrastructure programs need real-time visibility into EAC, SPI, CPI, budget variance, and burn rate — not weekly spreadsheet extracts. Dashboards must be drill-through from program to task level, with row-level security so each PM sees only their portfolio.

02
Reliable ETL Pipelines for Project Cost Data

Project cost data lives across Oracle databases, timesheet systems, contract management platforms, and billing systems. Feeding clean, timely, auditable data from all these sources into a reporting warehouse requires robust ETL with quality checks and lineage tracking built in — not bolted on after the fact.

03
OLAP Cubes for Multidimensional Project Analytics

Project finance teams need to slice performance by cost code, contract, region, and time period simultaneously. Star schema dimensional models and OLAP cubes are the infrastructure that makes this possible — and makes it fast enough to be useful in real-time leadership reviews.

04
C-Suite Earned Value Reporting That Drives Budget Decisions

Quarterly earned value presentations to senior leadership must translate EAC, SPI/CPI, and variance trends into budget recommendations — not just charts. The BI analyst is the person who bridges technical data and executive decision-making.
